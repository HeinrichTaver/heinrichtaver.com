# [heinrichtaver.com](https://www.heinrichtaver.com)

**Personal website** built with Astro, hosted on Vercel.


## 🛠️ Tech Stack

- [Astro](https://astro.build) (SSG framework)
- [Markdown](https://daringfireball.net/projects/markdown/) (Content)
- [Vercel](https://vercel.com) (Hosting/CDN)


##  🚀 Quick Start

### Clone & setup

```sh
git clone https://github.com/HeinrichTaver/heinrichtaver.com.git
cd heinrichtaver.com
```

For development tools management, this project uses [mise](https://mise.jdx.dev).
Use it to install the necessary development tools:

```sh
mise install
```

Finish by installing JavaScript dependencies:

```sh
npm install
```

### Development

```sh
npm run dev
```

### Build

```sh
npm run build
npm run preview
```
